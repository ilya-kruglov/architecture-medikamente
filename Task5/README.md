# Task 5: Разработка cutover-плана

## Цель
Разработать детальный план миграции (cutover-план) для перехода компании «Медикаменте» с устаревшей файловой монолитной архитектуры на целевую микросервисную платформу. Выбрать и обосновать стратегию миграции, определить этапы, риски, роли и меры по управлению изменениями.

## Выполненные работы
1. **Анализ стратегий** – рассмотрены три подхода (High-level design, Parallel run, Branch by abstraction), выбран и обоснован **Parallel run** как наиболее безопасный для медицинской и финансовой сферы.
2. **Cutover-план** – разработан поэтапный план на 10 недель с детализацией по дням для критических этапов.
3. **Управление рисками** – выявлены ключевые риски и предложены меры их снижения для каждого этапа.
4. **Роли и ответственность** – распределены обязанности между участниками команды.
