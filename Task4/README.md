# Task 4: Оценка узких мест при миграции

## Цель
Выявить потенциальные узкие места при миграции устаревшей монолитной системы «Медикаменте» на современную микросервисную архитектуру и предложить меры по их устранению.

## Выполненные работы
1. **Анализ ситуации** – изучены ключевые процессы и компоненты, затрагиваемые миграцией.
2. **Диаграмма Исикавы** – построена диаграмма «рыбья кость» для системного выявления причин узких мест.
3. **Категории проблем** – выделены 6 основных категорий: Инфраструктура, Программное обеспечение, Интеграция, Данные, Персонал, Процессы.
4. **Рекомендации** – составлен список мер по устранению выявленных узких мест с оценкой приоритетности.
