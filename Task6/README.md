# Task 6: Классификация данных

## Цель
Спроектировать движок классификации данных для аналитического хранилища (Data Lake) компании «Медикаменте», обеспечивающий автоматическое обнаружение, тегирование и маршрутизацию данных с учётом требований Privacy by Design, 152-ФЗ и масштабируемости.

## Ключевые задачи
1. **Движок классификации** – разработать компонент, который анализирует входящие данные, определяет их категорию чувствительности (ПДн/PII, Medical, Financial, Operational, Public) и применяет соответствующие теги.
2. **Многослойное хранилище** – предложить архитектуру Data Lake с зонами (Raw, Staging, Classified, Analytics), где конфиденциальные данные изолируются на ранних этапах.
3. **Метрики эффективности** – определить ключевые показатели качества классификации (precision, recall, F1, throughput, latency).
4. **Масштабируемость** – описать механизмы горизонтального масштабирования при росте объёмов данных и числа пользователей.
