# Архитектурное решение для компании «Медикаменте»

Репозиторий содержит решения финального задания 10-го спринта курса «Архитектура ПО: продвинутый уровень (System Design)» от Яндекс Практикум.

**Цель проекта** – спроектировать автоматизированную систему управления медицинскими данными, обеспечивающую соответствие требованиям российского законодательства по защите персональных данных (ПДн/PII), масштабируемость на 5-кратный рост нагрузки и возможность интеграции с новыми сервисами (мобильное приложение, BI/ML/AI).

**Ключевые артефакты:**
- Диаграммы архитектуры (C4 model)
- Модели данных и домены
- RBAC/ABAC политики
- План миграции данных
- Спецификации API
- Описание процессов обеспечения data privacy

**Структура репозитория:**
- `CONTEXT.md` – детальное описание контекста (компания, проблемы, цели, текущее состояние).
- `Task1/` … `Task6/` – решения каждого задания спринта.
