# Task 1: Анализ безопасности системы

## Цель задания
Провести анализ текущего состояния (As-Is) системы хранения и обработки конфиденциальных данных в компании «Медикаменте», выявить уязвимости и предложить меры по их устранению в соответствии с требованиями российского законодательства и лучшими архитектурными практиками (Privacy by Design, Data Minimization, Data Lineage).

## Выполненные работы
1. **Выявление конфиденциальных данных** – на основе анализа бизнес-процессов компании составлен полный перечень ПДн/PII и чувствительных данных.
2. **Построение DFD** – разработаны диаграммы потоков данных для ключевых процессов (контекстная и 5 детализированных).
3. **Аудит безопасности** – проведена оценка текущих мер защиты, составлен список проблемных зон с привязкой к требованиям 152-ФЗ.
4. **План улучшений** – предложена классификация данных, механизм тегирования и набор инструментов для обеспечения конфиденциальности на каждом этапе потока данных.
5. **Доработанные DFD** – на диаграммы нанесены точки применения мер защиты (шифрование, маскирование, аудит, контроль доступа).
