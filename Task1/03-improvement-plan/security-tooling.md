# Инструменты и меры обеспечения конфиденциальности данных

## 1. Инструменты по уровням защиты

### 1.1. Шифрование

| Инструмент | Назначение | Применение |
|------------|------------|------------|
| **Vault (HashiCorp)** | Управление ключами шифрования | Централизованное хранение и ротация ключей |
| **AWS KMS / GCP KMS** | Ключи шифрования | Для cloud-развертывания |
| **TLS 1.3 + mTLS** | Шифрование передачи | Все внутренние и внешние API |
| **AES-256-GCM** | Шифрование at rest | Базы данных, файловое хранилище |
| **Age / GPG** | Шифрование файлов | Для бэкапов и архивов |

### 1.2. Контроль доступа (IAM)

| Инструмент | Назначение | Применение |
|------------|------------|------------|
| **Keycloak / Auth0** | Identity Provider | Аутентификация и SSO |
| **Open Policy Agent (OPA)** | Policy Engine | ABAC на основе тегов |
| **AWS IAM / GCP IAM** | Управление доступом | Для cloud-ресурсов |
| **LDAP + AD** | Интеграция существующей инфраструктуры | Аутентификация сотрудников |

### 1.3. Аудит и мониторинг

| Инструмент | Назначение | Применение |
|------------|------------|------------|
| **ELK Stack (Elasticsearch, Logstash, Kibana)** | Сбор и визуализация логов | Централизованный аудит |
| **Victoria Metrics + Grafana** | Метрики и алертинг | Мониторинг безопасности |
| **Apache Atlas** | Data Lineage | Отслеживание происхождения данных |
| **Custom Audit Service** | Аудит доступа | Логирование каждого доступа к данным |

### 1.4. Маскирование и обезличивание

| Инструмент | Назначение | Применение |
|------------|------------|------------|
| **Apache Ranger** | Маскирование данных на уровне запросов | Динамическое маскирование в БД |
| **Custom Anonymization Service** | Обезличивание для аналитики | Генерация синтетических данных |
| **k-anonymity / Differential Privacy** | Обезличивание | Для ML/AI-нагрузок |

### 1.5. DLP и обнаружение

| Инструмент | Назначение | Применение |
|------------|------------|------------|
| **Custom DLP Service** | Обнаружение ПДн/PII в неструктурированных данных | На основе ML-моделей |
| **Apache Tika** | Извлечение текста из файлов | Для сканирования PDF, JPG, Excel |
| **Regex + NLP** | Паттерны обнаружения | Телефоны, email, адреса |

## 2. Меры по этапам потока данных

### 2.1. Сбор данных (Ingestion)
- ✅ TLS 1.3 для всех входящих соединений
- ✅ Аутентификация и авторизация на API Gateway
- ✅ Автоматическое тегирование при создании
- ✅ Валидация данных на соответствие DTO (не принимать лишнее)

### 2.2. Хранение данных (Storage)
- ✅ Шифрование at rest (AES-256)
- ✅ Разделение по категориям чувствительности (разные БД/схемы)
- ✅ Политики retention (автоматическое удаление)
- ✅ Резервное копирование с шифрованием

### 2.3. Обработка данных (Processing)
- ✅ ABAC на основе тегов (OPA)
- ✅ Аудит всех операций чтения/записи
- ✅ Маскирование при отображении в UI
- ✅ Logging без ПДн/PII (или с маскированием)

### 2.4. Передача данных (Transmission)
- ✅ mTLS для сервис-сервис
- ✅ API Gateway с rate limiting и validation
- ✅ Подпись запросов (JWT с ограниченным скоупом)
- ✅ Аудит исходящих данных

### 2.5. Удаление данных (Deletion)
- ✅ Безопасное удаление (не просто rm)
- ✅ Подтверждение удаления (soft delete + hard delete)
- ✅ Аудит удаления

## 3. Дорожная карта внедрения

| Этап | Срок | Меры |
|------|------|------|
| **1. Quick Wins** | 1 месяц | Шифрование дисков, внедрение TLS, базовая аутентификация |
| **2. Foundation** | 2-3 месяца | IAM (Keycloak), API Gateway, базовое тегирование |
| **3. Advanced** | 3-6 месяцев | ABAC (OPA), полный аудит, Data Lineage, DLP |
| **4. Continuous** | Постоянно | Мониторинг, обучение, улучшение политик |
