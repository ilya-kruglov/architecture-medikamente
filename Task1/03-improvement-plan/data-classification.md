# Классификация данных и способы защиты

## 1. Категории данных по чувствительности

| Категория | Описание | Примеры данных |
|-----------|----------|----------------|
| **ПДн/PII-Sensitive** | Данные, идентифицирующие личность, с высоким риском | ФИО, адрес, телефон, email, паспортные данные, СНИЛС |
| **ПДн/PII-General** | Общие персональные данные | Дата рождения, пол, место работы/учёбы |
| **Medical** | Медицинские данные (врачебная тайна) | Диагнозы, результаты анализов, история болезни, назначения |
| **Financial** | Финансовые данные | Информация об оплате, сумма, способ платежа |
| **Operational** | Операционные данные, не содержащие ПДн/PII | Журналы записей (без ФИО), статистика, метрики |
| **Public** | Публичные данные | Контактная информация компании, режим работы |

## 2. Способы защиты по категориям

| Категория | Шифрование | Обфускация/Маскирование | Обезличивание | Контроль доступа |
|-----------|------------|-------------------------|---------------|------------------|
| **ПДн/PII-Sensitive** | ✅ AES-256 при хранении, TLS 1.3 при передаче | Маскирование при отображении (ФИО: И*****в) | Только для аналитики (полная деидентификация) | RBAC + ABAC (строгий) |
| **ПДн/PII-General** | ✅ AES-256 при хранении | Частичное маскирование | Допустимо для BI | RBAC (стандартный) |
| **Medical** | ✅ AES-256 при хранении | Маскирование диагнозов для не-врачей | Только в агрегированном виде | ABAC (по специализации врача) |
| **Financial** | ✅ AES-256 | Полное маскирование для не-бухгалтеров | Не обезличивается | RBAC (только финансы) |
| **Operational** | ⚠️ Рекомендуется | Не требуется | Допустимо | RBAC (стандартный) |
| **Public** | ❌ Не требуется | Не требуется | Не требуется | Публичный доступ |

## 3. Матрица шифрования

| Состояние данных | Технология | Стандарт |
|------------------|------------|----------|
| **At Rest** (хранение) | Дисковое шифрование + шифрование на уровне приложения | AES-256-GCM |
| **In Transit** (передача) | TLS 1.3 + mTLS для сервис-сервис | RFC 8446 |
| **In Use** (обработка) | SGX / Confidential Computing (для ML/AI) | Intel SGX |

## 4. Политика маскирования

| Роль | Доступ к ПДн/PII-Sensitive | Доступ к Medical | Доступ к Financial |
|------|------------------------|------------------|-------------------|
| **Администратор** | Полный (в рамках работы) | ❌ | ❌ |
| **Врач** | Только своих пациентов | Полный (своих пациентов) | ❌ |
| **Кассир** | Только ФИО для оплаты | ❌ | Полный (операции) |
| **Бухгалтер** | ❌ | ❌ | Полный |
| **Склад** | ❌ | ❌ | ❌ (только суммы ТМЦ) |
| **Аналитик** | Обезличенные данные | Обезличенные данные | Агрегированные |

## 5. Сроки хранения (Data Retention)

| Категория | Срок хранения | Действие по истечении |
|-----------|---------------|----------------------|
| ПДн/PII-Sensitive | 5 лет после последнего обращения | Анонимизация + удаление |
| Medical | 25 лет (согласно законодательству) | Архивирование с шифрованием |
| Financial | 5 лет | Архивирование |
| Operational | 3 года | Агрегирование + удаление деталей |
| Audit logs | 1 год | Архивирование |
