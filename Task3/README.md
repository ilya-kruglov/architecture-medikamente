# Task 3: Оценка Data Encryption at Rest and In Transit

## Цель
Разработать стратегию защиты данных в системе «Медикаменте» с учётом требований шифрования на всех этапах жизненного цикла данных. Классифицировать данные по состоянию, чувствительности и рискам, предложить инструменты защиты и автоматизированного контроля.

## Выполненные работы
1. **Классификация данных** – составлена таблица с категориями, состояниями, профилями риска, обоснованием необходимости защиты.
2. **Стратегия шифрования** – описаны подходы для at rest, in transit, in use.
3. **Инструменты защиты** – перечень программных и аппаратных средств.
4. **Автоматизированный контроль** – средства мониторинга, аудита и управления ключами.
