# Реестр программных и аппаратных средств для защиты данных

## 1. Программные средства

| Категория | Инструмент | Версия (рекомендуемая) | Лицензия | Применение |
|-----------|------------|------------------------|----------|------------|

| **Шифрование at rest (файлы)** | age (from filippo.io) | 1.1+ | BSD‑3 | Шифрование файлов (сканы, PDF) |
| **Шифрование дисков** | LUKS (Linux) / BitLocker (Windows) | – | Open Source / Проприетарная | Дисковое шифрование серверов |
| **TLS / mTLS** | OpenSSL / BoringSSL | 3.0+ | OpenSSL / Google | Криптографические библиотеки |
| **Service Mesh** | Istio + Envoy | 1.20+ | Apache 2.0 | Автоматический mTLS между сервисами |
| **PKI** | Vault PKI Engine | – | – | Выпуск и ротация сертификатов |
| **SIEM** | Wazuh | 4.7+ | Open Source | Корреляция событий безопасности |
| **Логирование** | ELK Stack (Elasticsearch, Logstash, Kibana) | 8.x | Elastic License | Сбор и визуализация аудит‑логов |
| **Мониторинг** | Prometheus + Grafana | 2.x / 9.x | Apache 2.0 | Метрики статуса шифрования |
| **DLP** | Custom (Python + ML) | – | – | Обнаружение ПДн/PII в неструктурированных данных |
| **Автоматизация** | Terraform / Ansible | 1.6+ / 2.15+ | MPL 2.0 / GPL | Развёртывание и настройка защиты |
| **Policy Engine** | Open Policy Agent (OPA) | 0.60+ | Apache 2.0 | Применение политик шифрования и доступа |
| **Токенизация** | Vault Transit Engine | – | – | Токенизация данных карт и ПДн/PII |
| **Анонимизация** | Apache Spark + custom | 3.5+ | Apache 2.0 | Обезличивание данных для аналитики |

## 2. Аппаратные средства

| Категория | Средство | Назначение |
|-----------|----------|------------|
| **HSM (Hardware Security Module)** | NitroKey HSM / YubiHSM | Безопасное хранение мастер‑ключа, физическая защита |
| **TEE (Trusted Execution Environment)** | Intel SGX / AMD SEV | Защищённая обработка ПДн/PII в памяти (для ML/AI) |
| **Сетевые экраны** | Физические/виртуальные NGFW (например, pfSense, Cisco ASA) | Контроль сетевого трафика, изоляция сегментов с чувствительными данными |
| **Сертифицированные СКЗИ** | КриптоПро, ViPNet (для РФ) | Шифрование, соответствующее требованиям ФСБ (если необходимо) |
| **Безопасные бэкап‑устройства** | Ленточные библиотеки с шифрованием, облачные бэкапы с SSE | Защита резервных копий |

## 3. Реестр ключей и сертификатов (управление)

| Тип | Назначение | Срок действия | Ротация | Ответственный |
|-----|------------|---------------|---------|---------------|
| **Master Key** | Распаковка Vault | Бессрочный (хранится в HSM) | Только при компрометации | DPO / DevOps |
| **DEK (Data Encryption Key)** | Шифрование данных в БД | 90 дней | Автоматическая (Vault) | DevOps |
| **TLS‑сертификаты** | Шифрование in transit (внешние) | 1 год | Автоматическая (Vault PKI) | DevOps |
| **mTLS‑сертификаты** | Внутренние сервисы | 1 год | Автоматическая (Istio + Vault) | DevOps |
| **API‑ключи** | Интеграции (лаборатория, партнёры) | 6 месяцев | Ручная с уведомлением | Архитектор |
| **JWT‑секреты** | Подпись токенов | 30 дней | Автоматическая (Keycloak) | DevOps |
