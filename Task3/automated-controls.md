# Автоматизированный контроль защиты данных

## 1. Мониторинг шифрования
| Компонент | Инструмент | Что контролируется | Частота проверки |
|-----------|------------|---------------------|------------------|
| Дисковое шифрование | ОС‑утилиты (LUKS, BitLocker) + Prometheus exporter | Статус шифрования на всех узлах | Каждые 5 минут |
| Базы данных | Встроенные механизмы (PostgreSQL TDE, ClickHouse encryption) | Активация шифрования, отсутствие открытых таблиц с ПДн/PII | Ежедневно (скрипт) |
| Файловое хранилище | Сканер метаданных | Проверка, что все новые файлы зашифрованы | При загрузке (on‑the‑fly) + ночной скрипт |
| TLS‑сертификаты | Vault + Prometheus | Срок действия сертификатов, их валидность | Ежечасно, алерты за 30 дней до истечения |
| Ключи шифрования | Vault API + аудит | Ротация ключей, наличие активных ключей | Ежедневно |

## 2. Аудит доступа
- **Система:** ELK Stack + SIEM (например, Wazuh или Splunk).
- **Логируемые события:**
  - Все операции чтения/записи к зашифрованным данным.
  - Попытки доступа к ключам в Vault.
  - Изменения политик шифрования.
  - Сбои при шифровании/дешифровании.
- **Алерты:**
  - Множественные неудачные попытки дешифровки.
  - Доступ к данным с необычных IP/в нерабочее время.
  - Попытка доступа к ключам без соответствующих прав.

## 3. Проверка соответствия (Compliance Scanning)
- **Регулярные автоматические сканы** для выявления открытых ПДн/PII в нешифрованных хранилищах.
- Использование **DLP‑агентов** для обнаружения ПДн/PII в файлах и базах данных.
- **Отчёты о соответствии** формируются ежемесячно и отправляются DPO.

## 4. Управление политиками
- **Политика шифрования** централизованно хранится в Vault или отдельном Git‑репозитории.
- **Изменения политик** проходят код‑ревью и автоматическое тестирование (CI/CD).
- **Тесты на регрессию** – после изменений политик запускаются тесты, проверяющие, что чувствительные данные не появляются в открытом виде.

## 5. Инциденты и реагирование
- **Автоматическое оповещение** (email, Telegram, Slack) при обнаружении:
  - Нарушения шифрования.
  - Попытки эксфильтрации данных.
  - Истечения сертификатов.
- **Runbook** для ручного реагирования (блокировка доступа, смена ключей, расследование).

## 6. Инструменты автоматизированного контроля

| Инструмент | Назначение |
|------------|------------|
| **Vault** | Управление ключами, ротация, аудит доступа к ключам |
| **Prometheus + Grafana** | Сбор метрик и визуализация статуса шифрования |
| **ELK Stack** | Сбор и анализ логов аудита |
| **Wazuh / Splunk** | SIEM – корреляция событий, алерты |
| **Custom DLP Scanner** | Автоматическое обнаружение ПДн/PII в нешифрованных данных |
| **Terraform / Ansible** | Автоматизация развёртывания шифрования на инфраструктуре |
| **OPA (Open Policy Agent)** | Проверка политик шифрования в CI/CD и при рантайме |
