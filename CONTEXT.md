# Контекст компании «Медикаменте»

## Общие сведения
- Сфера деятельности: медицинские услуги (один офис).
- Штат: 20 административных сотрудников + 15 медицинских специалистов.
- Текущая ИТ-инфраструктура: ручная обработка данных (Excel, сканы, общий сетевой диск), учёт в «1С:Бухгалтерия предприятия» и «1С:Торговля и склад» (оба в файловом режиме), интеграция с ККМ через OLE.
- Сервер: Windows Server 2022 с AD, DNS, DHCP, LDAP, файловым сервером, Exchange Mail Server.

## Бизнес-цели
1. **Интеграция лаборатории анализов через API** – скрыть конфиденциальные данные, предотвратить несанкционированный доступ, обеспечить безопасность по умолчанию для будущих интеграций.
2. **Развитие аналитики и AI** – создать озеро данных (Data Lake) на основе Excel-файлов для автоматизации BI, ML и LLM.
3. **Разработка новых систем и миграция**:
   - Портал для клиентов (самозапись, просмотр своих данных)
   - Портал для ресепшена
   - Платёжный шлюз
   - CRM
   - Интеграция с лабораторией

## Проблемы и риски
- Несоответствие обработки ПДн/PII требованиям РФ (152-ФЗ).
- Отсутствие аудита доступа и контроля потоков данных.
- Ручная обработка, низкая масштабируемость при открытии новых филиалов.

## Архитектурные требования (НФТ)
- **Безопасность (конфиденциальность)**: защита чувствительных данных, возможность удаления по запросу клиента, шифрование, управление доступом (RBAC/ABAC).
- **Масштабируемость**: поддержка 5-кратного роста данных и количества сотрудников.
- **Сопровождаемость**: лёгкость внесения изменений.
- **Конфигурируемость**: настройка без доработок кода.

## Технологический стек (существующий и планируемый)
- **Существующий**: Excel, 1С (файловый режим), Windows Server, Exchange.
- **Планируемый (со стороны техдиректора)**: Java, Postgres, ClickHouse, Elastic, Kubernetes, Victoria Metrics.
- **Компетенции команды**: Python (Jupyter), администрирование сетей, бизнес-аналитика.

## Этапы развития (MVP и финал)
- **Промежуточное состояние (через 2 месяца)**: MVP – самозапись через портал, синхронизация с ресепшеном, категорирование данных и разграничение доступа.
- **Финальное состояние (через год)**: полная автоматизация, мобильное приложение, уведомления, аудит доступа, тегирование данных, автоматические проверки и алертинг.
